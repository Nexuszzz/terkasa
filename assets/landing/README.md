# Aset landing page TERKASA

- `source/`: PNG asli dari built-in image_gen, tidak dipakai langsung di browser.
- `prompts.json`: prompt, asal, dan tujuan setiap visual.
- `../../public/assets/landing/generated/`: versi WebP untuk website.
- `../../components/landing/`: komponen dan stylesheet khusus landing page.

Jalankan `node scripts/prepare-landing-assets.mjs` untuk membuat ulang WebP. Foto merupakan ilustrasi AI, bukan dokumentasi usaha tertentu. Identitas dan angka dalam demo bersifat fiktif. Komposisi poster dibuat dengan HTML/CSS agar teks tetap dapat disunting.

TERKASA · GATEWAY LOKAL

Hubungkan sesi Gemini Web.

Halaman ini menghubungkan akun Gemini milik Anda ke gateway lokal. Ini menggunakan sesi web, terpisah dari Google API resmi. Ketersediaan gambar mengikuti akun dan kuota Gemini Anda.

Cara menyiapkan sesi
  1. Buka Gemini Web dan masuk sendiri dengan akun yang ingin dipakai.
  2. Pada browser tersebut, buka DevTools (F12) → Application/Storage → Cookies → google.com atau gemini.google.com.
  3. Salin hanya nilai __Secure-1PSID dan __Secure-1PSIDTS ke dua kolom di bawah. Jangan kirim nilainya ke chat.
  4. Klik Hubungkan. Gateway memeriksa sesi sebelum menyimpannya secara lokal. Cookie browser dapat kedaluwarsa; jika perlu, ulangi dari sesi browser yang baru.

Sesi belum diverifikasi.

Credential disimpan hanya pada folder .state lokal yang diabaikan Git. Tidak ada ekstraksi cookie browser otomatis, pergantian banyak akun, atau pengiriman posting Instagram dari halaman ini.

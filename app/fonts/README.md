# Local font assets

Inter, Space Grotesk and JetBrains Mono are the same Latin variable font assets used by the original application. They were recovered from the existing local Next.js build in `D:\webcv\umkm-an-modal-components\.next\static\media` and renamed without modifying the font data.

`next/font/local` bundles them with the application, so building TERKASA does not require a connection to Google Fonts. The font families are distributed under SIL Open Font License 1.1; corresponding copyright and license notices are kept in this directory.
